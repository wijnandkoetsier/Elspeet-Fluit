# Koetsier Media

Webapp met de resultaten van de klanten van Koetsier Media (gisteren, 7 en 30 dagen), met per klant een detailpagina.

- Adres: https://wijnandkoetsier.github.io/READ.md/koetsier-media/
- De cijfers komen rechtstreeks van Windsor.ai (Meta, Google Ads, LinkedIn, ChatGPT-ads en GA4).
- Bij de eerste keer openen vul je je Windsor.ai-API-sleutel in. Die blijft alleen op het toestel (localStorage) en staat niet in deze repo.
- Opgehaalde cijfers blijven 3 uur op het toestel bewaard; **Vernieuwen** haalt ze direct opnieuw op.

**Op de telefoon zetten:**
- iPhone: open in Safari → **Deel** → **Zet op beginscherm**
- Android: open in Chrome → menu ⋮ → **App installeren**

**Bestanden:** `index.html` (opmaak), `app.js` (ophalen, berekeningen en schermen), `sw.js` (werkt ook zonder netwerk), `vendor/d3.min.js` (grafieken).
